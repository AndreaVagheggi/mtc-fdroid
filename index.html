MindTheClub F-Droid repository

The build for phones without Google services, with automatic update notifications.

Add this repository to F-Droid

How to install

  1. Install an F-Droid client: F-Droid, Droid-ify or Neo Store.
  2. Tap the button above, or add this address by hand:
    https://fdroid.mindtheclub.com/repo
  3. Install MindTheClub from the client, and updates will be offered there from now on.
  4. Notifications need a UnifiedPush distributor, for example ntfy, which is in F-Droid too.

Without F-Droid

The signed APK of every release is also on GitHub. Installed that way, updates are not automatic.
